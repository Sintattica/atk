# Internationalisation

[← Documentation index](../README.md)

Every label ATK shows goes through `Core\Language` ([source](../../src/Core/Language.php)), so translating an application means writing language files. This covers attribute labels, node titles, tab names, menu entries, buttons and error messages. ATK ships translations of its own strings in 25 languages in [`src/Resources/languages/`](../../src/Resources/languages).

## Language files

A language file is a PHP file that returns an array of `key => translation`. It is named after the ISO 639-1 code, e.g. `en.php` or `it.php`.

```php
<?php
// src/Modules/Crm/languages/en.php
return [
    'customers'                 => 'Customers',
    'title_customers_admin'     => 'Customer list',
    'name'                      => 'Name',
    'customers_status'          => 'Customer status',    // node-specific: <node>_<key>
    'tab_details'               => 'Details',
    'menu_customers'            => 'Customers',
    'link_customers_add'        => 'New customer',
    'error_end_before_start'    => 'The end date must follow the start date',
];
```

Files are looked up in three places. `Language::getLanguageDirForModule()` maps a module name to a directory:

| Module name | Directory |
|---|---|
| `atk` | `src/Resources/languages/` inside ATK |
| `langoverrides` | The `language_basedir` config key. The default is `languages/`, relative to the working directory, so set an absolute path (the skeleton uses `__DIR__ . '/../languages/'`). |
| any registered module | `languages/` next to the module class file (`Atk::moduleDir()`) |

## Lookup order

`Language::text($key, $module, $node = '', $lng = '', $firstfallback = '', $nodefaulttext = false, $modulefallback = false)` builds a list of modules to search:

1. the requested `$module`, if any;
2. `$firstfallback`, if given;
3. the override modules. By default this is only `langoverrides`, i.e. the application's `language_basedir`. Add more with `Language::getInstance()->addOverrideModule()`;
4. the fallback modules added with `addFallbackModule()`;
5. **all** registered modules, if `$modulefallback` is true or the `language_modulefallback` config key is set;
6. `atk`.

When `$module` is `atk`, the override modules go first. This lets the application override ATK's own strings in its `language_basedir` files.

ATK then tries these keys across that module list, in order:

1. strings set at runtime with `Language::getInstance()->setText($key, $text, $lng)`;
2. if a node is given: `<module>_<node>_<key>`, then `<node>_<key>`;
3. `<key>`.

If nothing matches, the result depends on `$nodefaulttext`:
- normally, ATK returns a default text made from the key: the `title_` prefix is removed, underscores become spaces, and the first letter is upper-cased, e.g. `customer_since` → `Customer since`;
- with `$nodefaulttext` set to true, it returns an empty string instead.

Enable `debug_translations` to log every missing key to the debug console.

`$key` may also be an array of keys. The first one that has a translation wins:

```php
Tools::atktext(['title_crm_customers', 'customers'], 'crm');
```

## Calling the translator

| Where | Call |
|---|---|
| Anywhere | `Tools::atktext($key, $module = '', $node = '', $lng = '', ...)`, a thin wrapper around `Language::text()` |
| In a node | `$this->text($key)`, which uses the node's module and type as context |
| In an attribute | `$this->text($key)`, which uses the owner node's context |
| In a Smarty template | `{atktext id="key"}`, `{atktext id="module.key"}` or `{atktext id="module.node.key"}`. Extra parameters are substituted into `[placeholders]` of the translation. |

## Which keys ATK looks up

| UI element | Keys tried |
|---|---|
| Attribute label | the attribute name, in the node context. So `<module>_<node>_<attr>`, `<node>_<attr>` and `<attr>` all work. `Attribute::setLabel()` bypasses translation. |
| Attribute help | the key passed to `Attribute::setHelp()` |
| Node title and action | `title_<module>_<node>_<action>`, `title_<node>_<action>`, `title_<action>`, then `title_<module>_<node>`, `title_<node>`, `<node>` together with `action_<module>_<node>_<action>`, `action_<node>_<action>`, `action_<action>`, `<action>` (`Node::nodeTitle()`) |
| Tab | `tab_<tab>`, then `<tab>` (`Node::buildTabs()`) |
| Menu item | `menu_<name>`, then `<name>`, in the item's module (`MenuBase::getMenuTranslation()`) |
| "Add" link on the list page | `link_<node>_add` (`AdminHandler`). For relations, `link_<relation>_add` or `link_<destination node>_add`. |
| Action confirmation | `confirm_<action>` or `confirm_<action>_multi` |
| Validation errors | the error code passed to `Tools::triggerError()`, e.g. `error_obligatoryfield` (ATK) or your own key |

## Choosing the language

`Language::getLanguage()` decides the language of the current request:

1. the `atklng` request parameter, if it is one of `supported_languages`;
2. the logged-in user's `auth_languagefield` column, if supported;
3. the browser's `Accept-Language` header, if `use_browser_language` is true and the language is supported;
4. the `language` config key (default `en`).

```php
// config/atk.php
'language'             => 'it',
'supported_languages'  => ['it', 'en'],
'language_basedir'     => __DIR__ . '/../languages/',
'use_browser_language' => false,
```

`Language::setLanguage($lng)` forces a language for the rest of the request. `Language::setSupportedLanguages([...])` changes the supported list at runtime.

## Tips

- **Shared words.** Put generic words (`name`, `description`, `status`) in the module file or in `language_basedir`. Use node-prefixed keys only where the same attribute name needs different labels in different nodes.
- **Menu labels.** Items built with the object API (`ActionItem`, `UrlItem`, …) have no module unless you call `setModule()`, so their labels are looked up in `language_basedir` and in ATK's files. See [Modules and menu](modules-and-menu.md#labels).
- **Overriding ATK strings.** To change one of ATK's own strings, such as `add` ("New"), redefine the key in your `language_basedir` file. Override modules are searched before `atk`.
